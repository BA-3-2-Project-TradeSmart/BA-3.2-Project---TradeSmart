# BA-3.2-Project---TradeSmart
This is an AI Solution for the used-vehicle market in South Africa.

Dealerships value trade-in vehicles manually, which is slow, inconsistent between consultants and unrecorded, so they lose money by overpaying or lose deals by underpaying. TradeSmart AI uses machine learning and NLP to give an instant, data-driven value range and record each vehicle’s reported condition.
